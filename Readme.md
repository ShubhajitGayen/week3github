Assignments
1. Bank Account Class

Create a BankAccount class with the following methods:

deposit() – Add money to the account.
withdraw() – Withdraw money from the account after checking the available balance.
display_balance() – Display the current account balance.

The program should use a constructor to initialize the account details.

2. Library Management System

Develop an object-oriented Library Management System.

The system should provide functionality to:

Add books
Remove books
Issue books
Return books
Display available books

Use classes and objects to represent books and the library.

3. Calculator Class with Exception Handling

Create a Calculator class that performs basic arithmetic operations.

The calculator should handle exceptions such as:

Division by zero
Invalid input
Other appropriate arithmetic errors

Use exception handling to prevent the program from terminating unexpectedly.

Mini Project – Week 3
Billing System (OOP-Based)

Create an object-oriented billing system using separate classes for products and bills.

Product Class

The Product class should contain:

name
price
quantity

It should represent an individual product purchased by a customer.

Bill Class

The Bill class should be responsible for:

Managing products
Calculating the subtotal
Calculating tax
Calculating the final total
Displaying the bill
Bill Format

The final bill should be displayed in a clear tabular format containing information such as:

Product	Price	Quantity	Total
Product Name	Price	Quantity	Amount

The bill should clearly show:

Product details
Subtotal
Tax
Final payable amount
Learning Objectives

By completing Week 3, students should understand how to:

Design classes and create objects.
Use constructors to initialize objects.
Implement methods inside classes.
Apply inheritance and polymorphism.
Handle runtime errors using exception handling.
Import and use Python's built-in libraries.
Build applications using object-oriented design.
Make different objects interact with each other.
Skill Gain

Real-world class design and object interaction

Students will gain practical experience designing reusable classes, managing object relationships, handling errors, and applying OOP concepts to a real-world billing application.
